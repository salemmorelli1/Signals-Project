Primary real-data endpoints

  • Permutation-invariant component reconstruction error
  • Scale-invariant signal-to-distortion ratio (SI-SDR)
  • Mixture reconstruction and failure rate
  • Receiver/day-clustered confidence intervals

Endpoints excluded from WiSig claims

  • Frequency-hop trajectory MSE
  • True phase-path RMSE
  • Physical channel-tap NMSE
  • Hardware deadline and live interception performance

PYTHONPATH=. python -m src.signals_project.wisig_realdata \ --dataset external_data/wisig/ManyRx.pkl \ --output external_data/derived/wisig_manyrx \ --mixtures-per-domain 25 --seed 2026 \ --trust-official-pickle
